# Phone Control Lite — Grid & Broadcast

Halaman unduhan dan launcher Windows untuk menampilkan preview sampai 30 HP Android dalam satu jendela. Klik preview untuk mengirim tap/swipe ke satu HP, atau pilih beberapa HP dan aktifkan broadcast untuk mengirim input yang sama ke perangkat terpilih.

- Landing page: `index.html`
- ZIP Windows: `downloads/PhoneControlLite-Windows.zip`
- Launcher: `PhoneControlLite.ps1` dan `Start-PhoneControlLite.bat`

Preview memakai snapshot ADB berkala, bukan video langsung. Kecepatan refresh dan broadcast bergantung pada PC, kabel dan hub USB. USB debugging serta persetujuan awal pada setiap HP diperlukan. Maksimum 30 perangkat ditampilkan.

Launcher mengunduh scrcpy/ADB Windows x64 dari rilis resmi Genymobile. scrcpy adalah proyek terpisah berlisensi Apache-2.0; Phone Control Lite bukan produk resmi Genymobile.
